# CHANGELOG

The package manifest targets `0.1.0-rc.8`, which replaces rc.7 as the candidate for the stable-readiness review because it migrates the database to schema 10, adds the single-writer daemon and file watcher, and changes the MCP search response shape. This does not mark the candidate as published or v0.1.0 as stable.

Release-specific changes and compatibility notes live in [rc.8 notes](docs/release-notes/v0.1.0-rc.8.md), [rc.7 notes](docs/release-notes/v0.1.0-rc.7.md), [rc.6 notes](docs/release-notes/v0.1.0-rc.6.md) and the earlier files in `docs/release-notes/`. Development evidence is recorded in [HISTORY-TRACKER.md](HISTORY-TRACKER.md).

The stable release decision remains pending validation of the published rc.8 artifact.
